# Example Project

This is an example open-source project showing how to structure and document nextjs project using different tech stacks.  
It demonstrates basic setup, usage, and contribution practices.

##

- Easy-to-follow structure
- Ready for contributions

## Features

- i18n feature using [next-intl](https://next-intl.dev/)

## Quickstart

1. check each branch `feature/*`, `example/*`, etc.
2. check the dedicated docs. e.g. `CONTRIBUTING.md`, etc.

```bash
git clone https://github.com/yourusername/example-project.git
cd example-project
# Install dependencies (example: Python)
pip install -r requirements.txt
python main.py
```
